# pickpocket/homebrew-tap

Homebrew tap for [**oms**](https://github.com/pickpocket/oh-my-soup) — a coding agent with the IDE wired in.

```sh
brew install pickpocket/tap/oms
```

`Formula/oms.rb` is generated from the published GitHub release assets by
[`scripts/ci-update-brew-formula.ts`](https://github.com/pickpocket/oh-my-soup/blob/main/scripts/ci-update-brew-formula.ts)
and pushed by the `release_brew` job on every release. Do not hand-edit it.
